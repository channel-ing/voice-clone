# MiniMax 声音复刻小工具

一个纯网页的小工具：上传一段音频，复刻出你自己的音色，自定义 `voice_id`，再用这个音色把文字合成语音，并且可以在网页里本地调整语速、音调、音量后试听和下载。

- 不需要安装，也没有后端，打开网页就能用
- 使用的是 MiniMax（国内站）的接口，需要你自己的 API Key
- 固定使用模型：`speech-02-turbo`

## 快速开始

1. 打开网页
2. 在「设置」里填入你自己的 MiniMax API Key，点「保存到本地」
3. 在「上传音频复刻」里选择音频文件，起一个 `voice_id`，点「开始复刻」
4. 复刻成功后，在「生成音频」里输入文字，点「生成音频」，再点「播放」试听

## 详细使用说明

### 第 1 步：获取 API Key

登录 MiniMax 开放平台（platform.minimaxi.com），在账户管理的「接口密钥」处创建一个 API Key，复制后粘贴到网页第一步的输入框里。

Key 只保存在你自己浏览器的本地存储里，不会上传到任何别的服务器，只会在你点击按钮时直接发给 MiniMax。

### 第 2 步：复刻声音

| 项目 | 要求 |
| --- | --- |
| 音频格式 | mp3、m4a、wav |
| 音频时长 | 10 秒到 5 分钟 |
| 文件大小 | 不超过 20MB |
| voice_id | 8–256 位，必须以字母开头，只能包含字母、数字、`-`、`_`，例如 `mySweetVoice01` |

录音建议：环境安静、只有一个人说话、没有背景音乐、吐字清晰，复刻效果会更好。

「试听文本」是可选的，填了的话复刻成功后会返回一段示例音频，可以直接听听像不像。

复刻成功后，这个 `voice_id` 会自动记录在下方「生成音频」的列表里，点一下就能选用；点标签上的 `×` 可以从本地列表里移除（不会删除 MiniMax 上的音色）。

### 第 3 步：生成音频

1. 输入或点选一个 `voice_id`（也可以手动输入之前已经复刻好的 ID）
2. 输入要合成的文字
3. 点「生成音频」，这一步会调用一次接口
4. 点「播放」试听

### 第 4 步：本地调整并下载

生成之后，下面三个滑块都是在你的浏览器里实时处理，不会再次调用接口，也不会产生额外费用：

- **语速**：0.5 倍到 2 倍
- **音调**：正负 12 个半音
- **音量**：0% 到 200%

调到满意后可以下载：

- **下载调整后的音频（wav）**：按当前滑块设置，在本地处理后下载
- **下载原始 mp3**：接口返回的原始音频，不含滑块调整

「重置」按钮可以把三个滑块恢复默认值。

## 在其他网站里使用复刻出来的 voice_id

复刻出的 `voice_id` 属于复刻时所用的那个 API Key 所在的账号。在别的网站或程序里调用语音合成时，需要：

- 使用**同一个账号**的 API Key
- 合成时使用同样的模型（建议保持 `speech-02-turbo`）
- 把这个 `voice_id` 填到对应位置

用别的账号的 Key，会提示找不到这个音色。

## 常见问题

**提示 Failed to fetch 或「可能是跨域被拦截」**

浏览器直接请求 MiniMax 接口时可能被跨域策略拦截。可以在页面的「高级：接口地址 / 代理」里，把接口地址改成你自己搭建的代理地址。

**复刻出的声音过一段时间不能用了**

按官方文档，复刻出的音色如果长时间没有被使用，会被自动删除，需要的话请定期用一下，或者重新复刻。

**调整音调、导出 wav 不能用**

变调功能依赖一个需要联网加载的组件（Tone.js）。如果网络没能加载它，页面会提示，并退回到只支持语速和音量。请检查网络后刷新页面。

**会产生费用吗**

复刻和语音合成都会调用 MiniMax 接口，可能产生费用，具体以 MiniMax 平台的计费规则为准。在页面里调整语速、音调、音量、下载文件不会产生费用。

## 安全提醒

- 请只在你信任的网址上填写 API Key
- 不要在公共或共用的电脑上保存 Key；用完后可清除浏览器站点数据
- 如果怀疑 Key 泄露，请立刻到 MiniMax 平台删除并重新生成
- 请只复刻你本人或已获得授权的声音，不要用于冒充他人

## 部署（GitHub Pages）

1. 把 `index.html` 放在仓库根目录
2. 仓库 Settings → Pages → Source 选 Deploy from a branch，分支选 `main`，文件夹选 `/ (root)`，保存
3. 几分钟后即可通过 `https://你的用户名.github.io/仓库名/` 访问
